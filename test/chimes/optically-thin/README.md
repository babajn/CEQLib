# EQCLib と CHIMES の比較

無照射・固定密度の4種類の単一セルを、両ライブラリの非平衡モードで計算した。1セル更新の CPU 時間は、今回の12条件すべてで EQCLib が短く、CHIMES の 1/1.58〜1/6.28 だった。純水素の再結合はよく一致した。温度も時間発展させた3条件では冷却履歴に差が出た。

時間履歴と計算時間の図は Jupyter ノートブックに保存した。Python 3 と Matplotlib が使えるカーネルでセルを先頭から実行すると、CSV から再描画できる。 [PlotEQCLibChimes.ipynb](../../../plot/PlotEQCLibChimes.ipynb)

## 計算結果

下表は初期状態から1回の更新で10万年進めた結果。温度と組成には相対許容誤差 `1e-8` の計算値を使用した。

| 条件 | 初期温度 | 水素核密度 | 10万年後の EQCLib | 10万年後の CHIMES |
|---|---:|---:|---:|---:|
| 純水素の再結合・温度固定 | 1,000 K | 10 cm⁻³ | H⁺ 分率 0.01544 | H⁺ 分率 0.01524 |
| 再結合ガス | 13,500 K | 10 cm⁻³ | 4,114 K、H⁺ 分率 0.04093 | 1,920 K、H⁺ 分率 0.02836 |
| 分子ガス | 100 K | 30 cm⁻³ | 67.01 K、H₂ 水素核分率 0.80000 | 24.61 K、H₂ 水素核分率 0.80000 |
| 高温ガス | 10⁶ K | 10 cm⁻³ | 6,196 K、H⁺ 分率 0.18358 | 3,727 K、H⁺ 分率 0.11214 |

純水素では10万年後の H⁺ 分率の差は CHIMES 比で約1.3%だった。分子ガスは両方で H₂ 分率をほぼ維持したが、初期の体積冷却率は CHIMES が1.61倍で、10万年後の温度にも差が残った。

高温ガスは 25,000 K を下回るまでに EQCLib で約7.83万年、CHIMES で約6.99万年かかった。時刻は温度履歴の閾値前後の2点から対数補間した。初期の冷却率は EQCLib で `8.65e-22`、CHIMES で `1.96e-19 erg cm⁻³ s⁻¹`。EQCLib は O I〜O III の時間発展に加え、高温では追跡元素の衝突電離平衡（CIE）の表で金属冷却を補う。

## 計算速度

各欄は **EQCLib / CHIMES** の順で、1回の更新あたりの単一コア CPU 時間の中央値を µs で示す。初期状態から同じ更新を繰り返し、各条件で5バッチを測定した。ウォームアップ、データ表の初期化と読み込み、CSV 出力を計測区間から外した。

| 条件 | 10年刻み | 1,000年刻み | 10万年刻み |
|---|---:|---:|---:|
| 純水素の再結合・温度固定 | 2.57 / 11.89 | 12.38 / 28.03 | 62.45 / 164.35 |
| 再結合ガス | 119 / 215 | 440 / 694 | 1,107 / 2,078 |
| 分子ガス | 71 / 231 | 144 / 436 | 357 / 2,239 |
| 高温ガス | 188 / 490 | 270 / 922 | 1,781 / 6,935 |

相対許容誤差は計測時に `1e-6`。`1e-8` に厳しくしても、全24更新を通じた最終温度の変化は最大0.0034%、H⁺ 分率の変化は最大 `1.9e-5` だった。CHIMES は `atol = 1e-3 × rtol` を化学種の許容誤差の基準とし、元素存在量に応じたスケーリングを有効にした。EQCLib と CHIMES では積分器の誤差制御や状態変数が異なる。

## 設定と再実行

- 3種類の熱化学セルは He/H = 0.10、C/H = 3×10⁻⁴、O/H = 5×10⁻⁴ の数比。初期の H⁺ 分率は再結合ガスが0.98、分子ガスが `1e-6`、高温ガスが1。初期の He・C・O は再結合ガスで中性10%・一価20%・二価70%、分子ガスで中性100%、高温ガスで二価100%。分子ガスの初期 H₂ 水素核分率は0.80。両ライブラリに同じ初期温度と組成を設定した。
- 遮蔽、外部 UV、ダスト、軟 X 線は無効。光学的に薄い条件で Case A を使った。CHIMES `d8f0fdb` の加熱計算は宇宙線電離率が厳密にゼロの場合に未初期化の反応率を読むため、CHIMES に限り `1e-50 s⁻¹` を設定した。10万年間で水素1原子あたりの一次電離の期待値は約 `3e-38`。関連箇所は CHIMES の `src/update_rates.c` と `src/chimes_cooling.c`。
- CHIMES は H・He と必要な C・O を有効にし、分子ネットワークは分子ガスの条件で有効にした。EQCLib は非平衡の温度係数表と CIE 冷却を使用し、CO は無効。高温の CIE 表には総金属質量分率 `Z ≈ 0.00822` を与えた。CHIMES との違いには、追跡する電離段階、分子種、冷却率、分子ガスの熱容量が含まれる。計算時間の比はこのネットワーク設定と時間幅に対応する。 [EQCLib の冷却設定](../../../README.md) · [CHIMES の設定](https://richings.bitbucket.io/chimes/user_guide/ChimesDriver/Parameters.html)
- Intel Xeon w5-3423 の1コアに固定し、GCC 12.3.0 の `-O3` で倍精度のライブラリをビルドした。EQCLib の現行ソースと GSL 2.7.1、CHIMES `d8f0fdb`、反応データ `1a837f8`、SUNDIALS 7.9.0 を使用した。CHIMES は標準の密行列ソルバーを使用した。

現行の元素別 CIE 表を使い、CHIMES と元素組成をそろえるために EQCLib の未追跡元素の冷却補完を無効にする。

EQCLib のリポジトリルートから実行する。

```bash
bash test/chimes/optically-thin/run.sh
```

`CHIMES_DIR` は `chimes/` と `chimes-data/` を含むディレクトリで、既定値は EQCLib の隣にある `Chimes/`。GSL は `GSL_DIR`（既定値 `$HOME/lib/gsl`）、SUNDIALS と HDF5 は `CHIMES_LOCAL`（既定値 `$CHIMES_DIR/.local`）で指定する。

EQCLib の初期化に使うスペクトルは `PEGASE_DIR` で指定する。 [必要なスペクトルと設定例](../../../README.md#pegase2-のスペクトルを指定する)

CSV の出力先は `test/out/chimes/optically-thin/`。別の出力先を使う場合はスクリプトにディレクトリを引数として渡し、ノートブックの `data_dir` に同じパスを設定する。
